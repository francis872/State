# STATE OS

Plataforma SaaS modular para gestión empresarial en la nube.

## Estructura principal

- apps/
  - frontend/ (Next.js)
  - backend/ (Node.js + Express)
- packages/ (librerías compartidas futuras)

## Módulos iniciales
- STATE Core (CRM)
- STATE Connect (Inbox omnicanal)
- STATE Growth (Pipeline de ventas)

## Stack
- Frontend: Next.js (React + TypeScript)
- Backend: Node.js + Express
- Base de datos: PostgreSQL
- ORM: Prisma
- Autenticación: JWT

## Instalación y uso

1. Instala dependencias en cada app.
2. Configura variables de entorno.
3. Ejecuta backend y frontend.

---

Este proyecto está listo para escalar y agregar nuevos módulos empresariales.
